# Data Model: 插件面板配置项

## 插件配置（宿主机侧）

| 字段 | 类型 | 默认值 | 热重载 | 校验 |
| --- | --- | --- | --- | --- |
| `prefix` | 字符串 | `demo` | 是 | 含非空白字符 |
| `demoEnabled` | 布尔 | `true` | 是 | 布尔值 |

- 未知键：加载失败。
- `apply` 收到的是引用对象，读取用 `.get()`。

## 表单草稿（浏览器侧）

| 字段 | 草稿文本 | 保存写入 |
| --- | --- | --- |
| `prefix` | 输入框文本 | 非空白 → 设置；空白 → 非法，阻止保存；“重置”清除并回到默认值 |
| `demoEnabled` | `true` 或 `false` | 设置布尔值 |

- 草稿只在保存时写入；离开页面丢弃。
- 状态：`available`、`writable`、`dirty`、`invalid`、`saving`、`failed`。
