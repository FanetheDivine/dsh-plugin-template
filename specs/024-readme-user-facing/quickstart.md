# Quickstart: README 面向用户与宪章文档结构调整

## 验证

1. 运行 `pnpm format && pnpm check`，全部通过。
2. 阅读 `README.md`：
   - 开头依次是插件名、npm 版本徽标与简介。
   - 不含安装命令、配置表、工具表与开发者内容。
3. 阅读宪章原则 III：
   - 找到「`README.md` 不计入单一归属」的条文。
   - 版本号为 2.1.0，Sync Impact Report 记录本次修订。
4. 检查 `AGENTS.md` 索引与 `docs/template-conversion.md` 对 README 的描述与宪章一致。
