# Data Model: 文档归属

本需求的「数据」是文档及其归属内容。每条信息只有一个归属文档，其他文档只放链接。

## 文档

| 文档 | 读者 | 归属内容 | 引用关系 |
| --- | --- | --- | --- |
| `README.md` | 插件用户 | 功能、安装、配置、工具 | 只链接 `AGENTS.md` |
| `AGENTS.md` | 每个会话的 Agent | 交互指令、写作规范、流程入口、文档索引 | 链接宪章与 `docs/` |
| 宪章 | 执行 Spec Kit 流程的 Agent 与维护者 | 原则、技术约束、开发流程、文档结构、治理与优先级 | 链接 `AGENTS.md` 的写作规范 |
| `docs/` | 开发者 | 工作机制、已知风险、开发说明与命令一览 | 规则链接宪章 |
| 代码注释 | 读代码的人 | 文件职责、函数与常量用途 | 约束链接宪章 |

## 优先级

1. 用户的明确要求。
2. 宪章。
3. `AGENTS.md` 与其他文档。

冲突时 Agent 先指出冲突条款及影响，再按高优先级执行。
