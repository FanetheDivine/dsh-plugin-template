# Data Model: 插件元数据国际化与规范

## 元数据资源文件

- 名称：`locale/<语言 id>.json`，语言 id 取宿主内置集合，本模板使用 `zh` 与 `en`。
- 字段：

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `meta.title` | string | 是 | 非空；单行；中文用中文，英文用 sentence case |
| `meta.description` | string | 是 | 非空；说明能力、用法与限制 |
| `meta.detail` | string | 否 | 本模板不声明，详情页回落 README |

- 校验：
  - 两份文件的 `meta` 键集必须一致。
  - 字符串不含 U+200B 与 U+FEFF。
  - 语言 id 与文件名一致。
  - 顶层只含 `meta`。

## 前端字典

- 名称：按命名空间组织，本模板命名空间为 `dsh-plugin-template`。
- 字段：`locale id → 键 → 模板字符串`；占位符写作 `{name}`。
- 校验：
  - 必须同时提供 `zh` 与 `en`。
  - 键集一致，文案非空。
  - 占位符在译文中原样保留。
  - 键名进入 `LocaleNamespaceMap`，组件经注入的 `t` 取值。

## 语言偏好

- 字段：语言 id；来源为用户在设置里的选择或浏览器语言匹配。
- 规则：
  - 设置选择写入宿主设置，跨浏览器生效。
  - 未设置时按浏览器语言匹配已注册语言，最后回落 `en`。
  - 元数据与字典缺该语言时按同一条回退链取值。

## 变更关系

- 新增一种语言时同时产生：一份元数据文件、一组字典条目、`package.json` 打包声明。
- 语言 id 决定文件名、字典键与设置里的显示名，三处必须一致。
