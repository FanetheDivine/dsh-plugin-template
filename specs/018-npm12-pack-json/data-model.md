# Data Model: npm 12 下包内容测试兼容

无持久化数据。解析函数的输入与输出如下。

## 打包报告

`npm pack --dry-run --json` 的 stdout 解析结果，两种形状都表示同一个包的报告集合。

| 形状 | 来源 | 结构 |
| --- | --- | --- |
| 数组 | npm ≤ 11 | `[包报告, ...]` |
| 对象 | npm ≥ 12 | `{ "<包名>": 包报告, ... }` |

校验规则：

- 数组按元素顺序取包报告。
- 对象按键声明的顺序取包报告，键名不参与校验。
- 其他类型（`null`、字符串、数字、布尔）报错，错误信息带输出片段。

## 包报告

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `files` | `{ path: string }[]` | 该包的文件列表，解析只读这一项 |

校验规则：

- 缺少 `files` 或 `files` 不是数组时，该包贡献空列表。
- `files` 中缺 `path` 的条目忽略。

## 文件路径集合

用例侧使用的 `Set<string>`，内容为全部包报告的 `files[].path`。

- 空报告得到空集合。
- 同一路径出现多次时去重。
