# Data Model: 协作场景的 spec 编号唯一性

## 实体

| 实体 | 载体 | 关键属性 |
| --- | --- | --- |
| Spec 编号 | 分支名、worktree 目录名、spec 目录名的前缀 | 三位以上数字；全局唯一；单调递增；不复用 |
| 占号分支 | `origin` 上的 `<type>/<NNN>-<slug>` | 创建流程最早写出的编号证据；指向 base ref 或后续提交 |
| Worktree | `worktrees/<NNN>-<slug>` | 本地检出，绑定同名本地分支 |
| Spec 目录 | `specs/<NNN>-<slug>` | 随分支合并进入 `main` |
| 冲突集合 | `git ls-remote --heads origin` 的结果 | 同一编号下的全部分支名；字典序最小者为保留者 |

## 编号规则

| 规则 | 内容 |
| --- | --- |
| 来源 | base ref 的 `specs/`、主工作区的 `specs/`、本地分支、远程分支 |
| 计算 | 全部来源中的最大编号加一 |
| 保证人 | 创建流程推送的占号分支 |
| 不复用 | 已废弃 spec 的远程分支保留，编号继续占用 |
| 一致性 | 分支名、worktree 目录名、spec 目录名使用同一编号 |

## 状态流转

```text
候选编号 → 本地分支 → 推送占号 → 唯一性校验
                              ├─ 无冲突或本分支保留 → 创建 worktree → 写 spec 目录 → 合并 → 清理
                              ├─ 同号且本分支排序靠后 → 删除占号 → 候选编号 +1 → 重试
                              └─ 推送失败 → 删除本地分支 → 中止（退出码 1）
```

## 校验数据

| 场景 | 输入 | 判定 |
| --- | --- | --- |
| 创建时 | 当前编号、`ls-remote --heads origin` 结果 | 同号分支中本分支名最小，或没有同号分支 |
| 交付前 | 当前编号、远程分支、base ref 的 `specs/` | 无同号的其它分支，且 base ref 无同号的其它 spec 目录 |

## 不变量

- 任意两个 spec 的编号不同，包括未合并、已合并与已废弃的 spec。
- 编号只增不减；删除分支不释放编号。
- 编号在分支名、worktree 目录名与 spec 目录名中保持一致。
